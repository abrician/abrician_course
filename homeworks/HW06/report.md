## 1. Dataset

- Какой датасет выбран: `S06-hw-dataset-02.csv`
- Размер: 18000 строк, 21 столбец
- Целевая переменная: `target`, бинарная классификация  
  Классы:  
  - 0 — ~73.7%  
  - 1 — ~26.3%
- Признаки: все признаки числовые; присутствуют целочисленные
  признаки с небольшой мощностью, которые можно рассматривать
  как категориальные-подобные.

## 2. Protocol

- Разбиение: данные разделены на train и test выборки
  в пропорции 75% / 25% с использованием train_test_split.
  Использовался random_state = 42 для воспроизводимости.
  Применялась стратификация по целевой переменной y.

- Подбор: для моделей DecisionTree, RandomForest и GradientBoosting
  выполнялся подбор гиперпараметров с помощью GridSearchCV
  с 5-кратной кросс-валидацией, только на train-выборке.

- Метрики: использовались accuracy, F1 и ROC-AUC.
  В условиях дисбаланса классов accuracy дополнялась метриками
  F1 и ROC-AUC, при этом ROC-AUC использовалась как основной
  критерий сравнения моделей.


## 3. Models

Опишите, какие модели сравнивали и какие гиперпараметры подбирали.

Минимум:

В работе сравнивались следующие модели:

- DummyClassifier — простой baseline, предсказывающий
  наиболее частый класс.

- LogisticRegression — линейная модель, реализованная
  через Pipeline со StandardScaler.

- DecisionTreeClassifier — дерево решений с контролем
  сложности (max_depth, min_samples_leaf), параметры
  подбирались через GridSearchCV.

- RandomForestClassifier — ансамбль деревьев решений,
  подбирались параметры, влияющие на сложность и
  разнообразие деревьев.

- GradientBoostingClassifier — boosting-модель,
  использован подбор числа деревьев, глубины и learning rate.

## 4. Results

Финальные метрики качества моделей на test-выборке
сохранены в файле `artifacts/metrics_test.json`.

Лучшее качество по метрике ROC-AUC показала модель
GradientBoostingClassifier, которая была выбрана
в качестве финальной.


## 5. Analysis

Для лучшей модели была построена confusion matrix,
которая показала адекватный баланс между precision
и recall для обоих классов.

Для интерпретации модели использовалась permutation
importance. Наиболее важные признаки оказывают
наибольшее влияние на качество предсказаний, что
соответствует ожиданиям для синтетического датасета
с нелинейными взаимодействиями признаков.


## 6. Conclusion

- Ансамблевые модели превосходят baseline и одиночные деревья.
- RandomForest и GradientBoosting показывают устойчивое качество
  на сложных данных.
- Использование F1 и ROC-AUC критично при наличии дисбаланса классов.
- Честный ML-протокол с раздельными train/test и CV на train
  позволяет избежать переобучения и утечки данных.
