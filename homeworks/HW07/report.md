## 2. Protocol

Для всех датасетов использовался единый и воспроизводимый unsupervised-протокол.
Препроцессинг включал масштабирование числовых признаков с помощью StandardScaler. При наличии пропусков применялся SimpleImputer (median для числовых и most_frequent для категориальных признаков). Для dataset-04 категориальные признаки были закодированы с использованием OneHotEncoder. Весь препроцессинг был реализован через Pipeline и ColumnTransformer и одинаково применялся ко всем моделям внутри одного датасета.
Для KMeans выполнялся подбор числа кластеров в диапазоне от 2 до 20 с фиксированными random_state и n_init. Для второго алгоритма подбирались параметры eps (DBSCAN) либо linkage при фиксированном числе кластеров (AgglomerativeClustering). Выбор лучшего решения осуществлялся на основе значений silhouette score с учётом интерпретируемости и специфики данных.
Качество кластеризации оценивалось с помощью внутренних метрик: silhouette score, Davies–Bouldin score и Calinski–Harabasz score. Для DBSCAN метрики рассчитывались только на non-noise объектах, при этом отдельно анализировалась доля шума.
Для визуализации результатов использовалась PCA-проекция в двумерное пространство. PCA применялась исключительно для визуального анализа и не использовалась при выборе модели.

## 4. Results

Для каждого датасета – краткая сводка результатов.

- Лучший метод и параметры: KMeans, k = 2

### 4.3 Dataset C

## 5. Analysis

### 5.1 Сравнение алгоритмов (важные наблюдения)

KMeans показал высокое качество на датасетах с компактной кластерной структурой, но оказался чувствителен к нелинейности и выбросам. DBSCAN выиграл на данных с плотностной структурой и шумом, где KMeans теряет адекватность. Агломеративная кластеризация показала сопоставимые результаты, но редко превосходила KMeans. Наибольшее влияние на результат оказали масштабирование признаков, наличие выбросов и плотностные различия.

### 5.2 Устойчивость (обязательно для одного датасета)

Для dataset-01 была проведена проверка устойчивости KMeans с пятью запусками при разных random_state. Все разбиения оказались идентичными, а значения Adjusted Rand Index между всеми парами запусков равны 1.0. Это свидетельствует о полной устойчивости найденной кластерной структуры и отсутствии зависимости от инициализации.

### 5.3 Интерпретация кластеров

Кластеры интерпретировались через анализ структуры данных и визуализацию в пространстве главных компонент. Для компактных кластеров наблюдаются различия в уровнях ключевых числовых признаков, а для плотностных кластеров — чёткое отделение шумовых объектов. Полученные разбиения являются логичными и согласуются с внутренними метриками качества.

## 6. Conclusion

- Масштабирование признаков критически важно для distance-based методов.
- KMeans эффективен на компактных и хорошо разделимых данных, но чувствителен к форме кластеров.
- DBSCAN лучше справляется с шумом и нелинейной структурой.
- Внутренние метрики необходимо интерпретировать совместно, а не по отдельности.
- PCA полезна для визуализации, но не должна использоваться как критерий качества.
- Устойчивость разбиений является важной частью честного unsupervised-эксперимента.
