# Описание данных проекта

## Общая информация

В проекте используются открытые синтетические текстовые материалы на русском языке по двум темам: документация Python и концепции машинного обучения. Все данные написаны специально для проекта и не содержат персональной или конфиденциальной информации.

---

## Источники данных

| Папка | Тип данных | Источник |
|-------|-----------|---------|
| `data/ml_docs/` | Учебные материалы по ML | Синтетический (написано вручную для проекта) |
| `data/python_docs/tutorial/` | Туториалы по Python | Синтетический (адаптировано из официальной документации) |
| `data/python_docs/reference/` | Справочник по Python | Синтетический (адаптировано из официальной документации) |
| `data/python_docs/library/` | Стандартная библиотека Python | Синтетический (адаптировано из официальной документации) |

---

## Файлы в датасете

### ML-материалы (`data/ml_docs/`)

| Файл | Содержание |
|------|-----------|
| `overfitting.txt` | Переобучение: причины, признаки, методы борьбы |
| `underfitting.txt` | Недообучение: причины, признаки, диагностика |
| `classification.txt` | Задача классификации: алгоритмы, метрики |
| `regression.txt` | Задача регрессии: алгоритмы, метрики |
| `train_test_split.txt` | Разбиение данных: подходы, правила, кросс-валидация |
| `neural_networks.txt` | Нейронные сети: архитектура, обучение, типы |
| `embeddings.txt` | Эмбеддинги: виды, sentence-transformers, семантический поиск |

| Файл | Содержание |

## Характеристики данных

- **Язык:** русский
- **Формат:** plain text (.txt)
- **Кодировка:** UTF-8
- **Объём:** ~14 файлов, ~150-400 слов каждый
- **Тип:** открытые синтетические данные

---

## Назначение данных

Данные используются как база знаний для RAG-сервиса:
1. Загружаются и очищаются на этапе подготовки данных.
2. Разбиваются на чанки (фрагменты) для индексирования.
3. Индексируются методами TF-IDF и sentence-transformers.
4. По ним производится поиск в ответ на вопросы пользователя.
