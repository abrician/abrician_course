Строки и методы работы со строками в Python (String Methods)

Строка (str) — один из самых используемых типов данных в Python. Строки неизменяемы: любая операция создаёт новую строку.

Создание строк:
s1 = "Привет"
s2 = 'Мир'
s3 = """Многострочная
строка"""

# f-строки (f-strings) — самый удобный способ форматирования
name = "Иван"
age = 25
s4 = f"Меня зовут {name}, мне {age} лет"

Основные методы строк:
text = "  Привет, Мир!  "

# Регистр
text.upper()          # → "  ПРИВЕТ, МИР!  "
text.lower()          # → "  привет, мир!  "
text.title()          # → "  Привет, Мир!  "

# Очистка пробелов
text.strip()          # → "Привет, Мир!"  (оба конца)
text.lstrip()         # → "Привет, Мир!  " (только слева)
text.rstrip()         # → "  Привет, Мир!" (только справа)

# Поиск
"Мир" in text                    # → True
text.find("Мир")                 # → 9  (индекс начала, -1 если нет)
text.count("и")                  # → 2  (количество вхождений)
text.startswith("  Привет")      # → True
text.endswith("!  ")             # → True

# Замена
text.replace("Мир", "Python")   # → "  Привет, Python!  "

# Разбиение и объединение
sentence = "яблоко,банан,апельсин"
fruits = sentence.split(",")    # → ["яблоко", "банан", "апельсин"]
", ".join(fruits)               # → "яблоко, банан, апельсин"

# Разбиение на строки
text.splitlines()               # разбивает по переносам строк

Проверки:
"123".isdigit()     # True — только цифры
"abc".isalpha()     # True — только буквы
"abc123".isalnum()  # True — буквы и цифры
"  ".isspace()      # True — только пробелы

Работа с текстом в NLP контексте:
import re

text = "Привет! Как дела? Python - это круто."

# Удаление знаков пунктуации
clean = re.sub(r'[^\w\s]', '', text)

# Разбиение на слова
words = text.split()

# Нормализация: нижний регистр + очистка
normalized = text.lower().strip()
tokens = normalized.split()

# Длина текста
len(text)           # количество символов
len(text.split())   # количество слов
