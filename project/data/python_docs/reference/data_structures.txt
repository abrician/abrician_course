Структуры данных в Python (Data Structures)

Python предоставляет встроенные структуры данных, которые покрывают большинство задач программирования.

Список (List):
Упорядоченная изменяемая коллекция. Элементы могут повторяться.

my_list = [1, 2, 3, "текст", True]

# Основные операции
my_list.append(4)          # добавить в конец
my_list.insert(0, 0)       # вставить на позицию 0
my_list.remove("текст")    # удалить первое вхождение
my_list.pop()              # удалить и вернуть последний элемент
my_list.pop(0)             # удалить по индексу
len(my_list)               # длина списка

# Срезы (slicing)
nums = [0, 1, 2, 3, 4, 5]
nums[1:4]    # → [1, 2, 3]
nums[:3]     # → [0, 1, 2]
nums[3:]     # → [3, 4, 5]
nums[::-1]   # → [5, 4, 3, 2, 1]  (реверс)

Словарь (Dictionary):
Коллекция пар ключ-значение. Ключи уникальны.

person = {"name": "Иван", "age": 25, "city": "Москва"}

# Доступ к значениям
person["name"]              # → "Иван"
person.get("email", "N/A")  # безопасный доступ, без ошибки если нет ключа

# Изменение
person["age"] = 26
person["email"] = "ivan@example.com"

# Перебор
for key, value in person.items():
    print(f"{key}: {value}")

person.keys()    # все ключи
person.values()  # все значения

Множество (Set):
Коллекция уникальных элементов. Не упорядочена.

my_set = {1, 2, 3, 2, 1}  # → {1, 2, 3}

my_set.add(4)
my_set.remove(1)

# Операции над множествами
a = {1, 2, 3}
b = {2, 3, 4}
a & b   # пересечение → {2, 3}
a | b   # объединение → {1, 2, 3, 4}
a - b   # разность → {1}

Кортеж (Tuple):
Упорядоченная неизменяемая коллекция.

coords = (55.7558, 37.6176)  # широта и долгота Москвы
x, y = coords                # распаковка

Когда использовать что:
- List — когда нужна изменяемая упорядоченная коллекция.
- Dict — когда нужен быстрый поиск по ключу.
- Set — когда нужны уникальные элементы или операции над множествами.
- Tuple — когда данные не должны меняться (координаты, RGB-цвета).

Встроенные функции для коллекций:
len([1,2,3])        # длина → 3
sum([1,2,3])        # сумма → 6
min([3,1,2])        # минимум → 1
max([3,1,2])        # максимум → 3
sorted([3,1,2])     # сортировка → [1,2,3]
list(range(5))      # → [0,1,2,3,4]
