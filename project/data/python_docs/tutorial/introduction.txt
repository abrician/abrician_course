Введение в Python

Python — это высокоуровневый язык программирования с динамической типизацией и простым синтаксисом. Он широко используется в науке о данных, веб-разработке, автоматизации и искусственном интеллекте.

Основные особенности Python:
- Простой и читаемый синтаксис — код похож на псевдокод.
- Динамическая типизация — не нужно объявлять тип переменной.
- Интерпретируемый язык — выполняется построчно.
- Огромная экосистема библиотек — NumPy, pandas, scikit-learn, FastAPI и тысячи других.
- Кросс-платформенный — работает на Windows, macOS, Linux.

Базовые типы данных в Python:
- int — целые числа: 42, -7, 0
- float — числа с плавающей точкой: 3.14, -0.5
- str — строки: "привет", 'мир'
- bool — логические значения: True, False
- list — список: [1, 2, 3]
- dict — словарь: {"ключ": "значение"}
- tuple — неизменяемый список: (1, 2, 3)
- set — множество уникальных значений: {1, 2, 3}

Первая программа:
print("Привет, мир!")  # Выводит текст на экран

Переменные:
x = 10
name = "Python"
is_cool = True

Арифметические операции:
a = 10 + 5    # сложение → 15
b = 10 - 3    # вычитание → 7
c = 4 * 3     # умножение → 12
d = 10 / 3    # деление → 3.333...
e = 10 // 3   # целочисленное деление → 3
f = 10 % 3    # остаток от деления → 1
g = 2 ** 8    # степень → 256

Установка Python:
Скачайте с официального сайта python.org версию 3.10 или новее.
Проверьте установку: python --version
