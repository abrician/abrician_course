Функции в Python (Functions)

Функция — это именованный блок кода, который можно вызвать многократно. Функции помогают организовать код, избежать повторений и сделать программу понятнее.

Определение функции:
def greet(name):
    """Приветствует пользователя по имени."""
    return f"Привет, {name}!"

result = greet("Иван")
print(result)  # Привет, Иван!

Параметры и аргументы:

# Позиционные аргументы
def add(a, b):
    return a + b

add(3, 5)  # → 8

# Аргументы по умолчанию
def power(base, exponent=2):
    return base ** exponent

power(3)     # → 9  (exponent=2 по умолчанию)
power(3, 3)  # → 27

# Именованные аргументы (keyword arguments)
def describe(name, age, city):
    return f"{name}, {age} лет, из {city}"

describe(age=25, city="Москва", name="Иван")

# *args — переменное число позиционных аргументов
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3, 4)  # → 10

# **kwargs — переменное число именованных аргументов
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Иван", age=25)

Lambda-функции:
Короткие анонимные функции в одну строку.

square = lambda x: x ** 2
square(5)  # → 25

# Полезны с sorted, map, filter
numbers = [3, 1, 4, 1, 5, 9]
sorted_nums = sorted(numbers, key=lambda x: -x)  # по убыванию

Область видимости (Scope):
- Локальные переменные — живут только внутри функции.
- Глобальные — определены вне функций, доступны везде.

x = 10  # глобальная

def func():
    y = 5   # локальная, недоступна снаружи
    print(x)  # можно читать глобальные переменные
