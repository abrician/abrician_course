Эмбеддинги (Embeddings)

Эмбеддинги — это числовые представления объектов (слов, предложений, документов) в виде векторов в многомерном пространстве. Близкие по смыслу объекты имеют близкие векторы.

Зачем нужны эмбеддинги:
Компьютер не понимает текст напрямую — он работает с числами. Эмбеддинги позволяют преобразовать текст в числовой вектор таким образом, чтобы сохранить смысловые отношения между словами и предложениями.

Примеры эмбеддингов:
- Word2Vec — один из первых алгоритмов. Каждое слово → вектор. "Король" - "Мужчина" + "Женщина" ≈ "Королева".
- GloVe — похож на Word2Vec, основан на совместной встречаемости слов.
- FastText — учитывает подслова (морфемы). Хорошо для редких и составных слов.
- BERT — контекстные эмбеддинги. Одно и то же слово получает разный вектор в зависимости от контекста.
- Sentence-BERT (SBERT) — эмбеддинги целых предложений. Идеален для семантического поиска.

Sentence-Transformers:
Библиотека для создания эмбеддингов предложений на основе трансформеров.

from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
sentences = ["Как работает переобучение?", "Что такое dropout?"]
embeddings = model.encode(sentences)
# embeddings — массив numpy размером (2, 384)

Популярные модели:
- all-MiniLM-L6-v2 — маленькая и быстрая. 384 измерения. Хорошее качество.
- all-mpnet-base-v2 — лучшее качество, но медленнее. 768 измерений.
- paraphrase-multilingual-MiniLM-L12-v2 — многоязычная модель.

Семантический поиск с эмбеддингами:
1. Создаём эмбеддинги для всех документов в базе.
2. Создаём эмбеддинг запроса пользователя.
3. Вычисляем cosine similarity между запросом и каждым документом.
4. Возвращаем документы с наибольшим сходством.

Косинусное сходство (Cosine Similarity):
Мера близости двух векторов. Значение от -1 до 1.
- 1.0 — векторы идентичны (документы об одном).
- 0.0 — векторы перпендикулярны (нет связи).
- -1.0 — векторы противоположны.

from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

similarity = cosine_similarity([query_embedding], doc_embeddings)
top_indices = np.argsort(similarity[0])[::-1][:3]  # топ-3 результата
