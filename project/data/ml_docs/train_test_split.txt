Разбиение данных на обучающую и тестовую выборки (Train-Test Split)

Разбиение данных — обязательный шаг при разработке модели машинного обучения. Данные делятся на части: для обучения модели и для проверки её качества.

Зачем нужно разбиение:
Если обучить и оценить модель на одних и тех же данных, результат будет оптимистично завышен. Модель "запоминает" данные вместо того, чтобы находить общие закономерности. Тестовая выборка имитирует новые, ранее не виденные данные.

Типичные соотношения:
- 80% train / 20% test — стандартное разбиение.
- 70% train / 15% val / 15% test — если нужна валидационная выборка для настройки гиперпараметров.
- 60% / 20% / 20% — при небольшом объёме данных.

Ключевые понятия:
- Train (обучающая) — данные, на которых модель учится.
- Validation (валидационная) — данные для подбора гиперпараметров. Модель не учится на них.
- Test (тестовая) — данные для финальной оценки. Используется только один раз в конце.

Важные правила:
1. Всегда использовать random_state для воспроизводимости результатов.
2. При несбалансированных классах использовать stratify для сохранения пропорций.
3. Не смотреть на тестовые данные до финальной оценки — это утечка данных (data leakage).

Кросс-валидация (Cross-Validation):
Более надёжный метод. Данные делятся на K частей (folds). Модель обучается K раз, каждый раз используя другую часть как валидационную. Результат — среднее по K итерациям.

Пример в коде (sklearn):
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,       # 20% — тест
    random_state=42,     # для воспроизводимости
    stratify=y           # сохраняет пропорции классов
)

# Кросс-валидация
from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')
print(f"CV Score: {scores.mean():.3f} ± {scores.std():.3f}")
