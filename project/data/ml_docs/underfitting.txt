Недообучение (Underfitting)

Недообучение — это ситуация, когда модель слишком проста и не может уловить закономерности даже в обучающих данных. Модель плохо работает как на обучающих, так и на тестовых данных.

Причины недообучения:
- Модель слишком простая для задачи (например, линейная модель для нелинейных данных).
- Недостаточное время обучения (мало эпох).
- Слишком высокая регуляризация, которая "сковывает" модель.
- Неправильный выбор признаков (features) — важные данные не включены.

Признаки недообучения:
- Низкая точность на обучающих данных.
- Низкая точность на тестовых данных.
- Train loss и validation loss оба высокие.

Методы борьбы с недообучением:
1. Использовать более сложную модель — добавить слои, увеличить число параметров.
2. Добавить больше признаков (feature engineering).
3. Увеличить время обучения (больше эпох).
4. Уменьшить регуляризацию.
5. Попробовать другой алгоритм — например, вместо линейной регрессии использовать дерево решений.

Соотношение переобучения и недообучения:
Это называется компромисс смещения и дисперсии (Bias-Variance Tradeoff).
- Недообучение = высокое смещение (bias) — модель систематически ошибается.
- Переобучение = высокая дисперсия (variance) — модель слишком чувствительна к данным.
- Цель — найти баланс между ними.

Проверка через кривые обучения (learning curves) — самый надёжный способ диагностировать недообучение или переобучение.
