Переобучение (Overfitting)

Переобучение — это ситуация, когда модель машинного обучения слишком хорошо подстраивается под обучающие данные, но плохо работает на новых, ранее не виденных данных.

Причины переобучения:
- Слишком сложная модель (много параметров) относительно объёма данных.
- Недостаточное количество обучающих примеров.
- Обучение слишком долго (слишком много эпох).
- Отсутствие регуляризации.

Признаки переобучения:
- Высокая точность (accuracy) на обучающих данных.
- Низкая точность на валидационных или тестовых данных.
- Большая разница между train loss и validation loss — validation loss растёт, пока train loss падает.

Методы борьбы с переобучением:
1. Регуляризация L1 и L2 — добавляет штраф за большие веса модели.
2. Dropout — случайно отключает нейроны во время обучения.
3. Ранняя остановка (Early Stopping) — останавливает обучение, когда validation loss перестаёт улучшаться.
4. Увеличение объёма данных (Data Augmentation) — создаёт новые примеры из имеющихся.
5. Уменьшение сложности модели — использовать более простую архитектуру.
6. Кросс-валидация — оценивать модель на разных разбивках данных.

Пример в коде (sklearn):
from sklearn.linear_model import Ridge  # Ridge — линейная регрессия с L2-регуляризацией
model = Ridge(alpha=1.0)  # alpha — сила регуляризации

Переобучение — это одна из главных проблем в машинном обучении. Хорошая модель должна обобщать закономерности, а не заучивать конкретные примеры.
