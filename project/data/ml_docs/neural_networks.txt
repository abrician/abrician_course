Нейронные сети (Neural Networks)

Нейронная сеть — это вычислительная модель, вдохновлённая работой мозга. Состоит из слоёв нейронов (узлов), которые передают сигналы друг другу с определёнными весами.

Структура нейронной сети:
- Входной слой (Input Layer) — принимает данные (признаки).
- Скрытые слои (Hidden Layers) — обрабатывают данные, извлекают признаки. Чем больше слоёв, тем "глубже" сеть.
- Выходной слой (Output Layer) — выдаёт результат (классификация или число).

Как работает обучение:
1. Прямой проход (Forward Pass) — данные проходят через сеть, получаем предсказание.
2. Вычисление ошибки (Loss) — сравниваем предсказание с реальным ответом.
3. Обратное распространение (Backpropagation) — вычисляем градиенты ошибки по весам.
4. Обновление весов (Optimizer) — изменяем веса в направлении уменьшения ошибки.

Функции активации:
- ReLU (Rectified Linear Unit) — f(x) = max(0, x). Самая популярная для скрытых слоёв.
- Sigmoid — f(x) = 1/(1+e^-x). Выход от 0 до 1. Используется для бинарной классификации.
- Softmax — для многоклассовой классификации. Выдаёт вероятности классов.
- Tanh — выход от -1 до 1.

Оптимизаторы:
- SGD (Stochastic Gradient Descent) — базовый оптимизатор.
- Adam — адаптивный оптимизатор, самый популярный. Хорошо работает на большинстве задач.
- RMSprop — хорош для рекуррентных сетей.

Функции потерь (Loss Functions):
- Cross-Entropy Loss — для классификации.
- MSE (Mean Squared Error) — для регрессии.
- Binary Cross-Entropy — для бинарной классификации.

Типы нейронных сетей:
- MLP (Multilayer Perceptron) — полносвязная сеть для табличных данных.
- CNN (Convolutional Neural Network) — для изображений.
- RNN/LSTM/GRU — для последовательностей (текст, временные ряды).
- Transformer — современная архитектура для NLP задач.

Гиперпараметры:
- Learning rate (скорость обучения) — насколько сильно обновляются веса.
- Batch size — сколько примеров обрабатывается за раз.
- Epochs — сколько раз модель видит все данные.
- Количество слоёв и нейронов — сложность сети.
