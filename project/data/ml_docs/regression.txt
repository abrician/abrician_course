Регрессия (Regression)

Регрессия — задача машинного обучения, в которой нужно предсказать непрерывное числовое значение. Например: цена квартиры, температура завтра, объём продаж.

Отличие от классификации:
- Классификация предсказывает категорию (класс).
- Регрессия предсказывает число.

Популярные алгоритмы регрессии:
1. Линейная регрессия (Linear Regression) — предсказывает значение как линейную комбинацию признаков. Простая и интерпретируемая.
2. Полиномиальная регрессия — расширение линейной для нелинейных зависимостей.
3. Ridge регрессия — линейная регрессия с L2-регуляризацией (борьба с переобучением).
4. Lasso регрессия — линейная регрессия с L1-регуляризацией (обнуляет незначимые признаки).
5. Дерево решений для регрессии (Decision Tree Regressor).
6. Случайный лес для регрессии (Random Forest Regressor).
7. Градиентный бустинг (Gradient Boosting, XGBoost) — мощный метод для табличных данных.

Метрики качества регрессии:
- MAE (Mean Absolute Error) — средняя абсолютная ошибка. Легко интерпретировать.
- MSE (Mean Squared Error) — среднеквадратичная ошибка. Штрафует за большие ошибки.
- RMSE (Root MSE) — корень из MSE. В тех же единицах, что и целевая переменная.
- R² (R-squared) — доля объяснённой дисперсии. 1 = идеально, 0 = модель не лучше среднего.

Пример в коде (sklearn):
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
print(f"MAE: {mae:.2f}, R²: {r2:.3f}")
