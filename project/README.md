## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - EDA, прототипы моделей, отдельные эксперименты.
- `src/` – основной код проекта:
  - модули для работы с данными;
  - обучение моделей;
  - запуск сервиса/скриптов.
- `data/` – демонстрационные/учебные данные:
  - **только открытые, синтетические или обезличенные данные;**
  - при необходимости – небольшие выборки для быстрого запуска.
- `configs/` – конфигурационные файлы:
  - `.yaml`, `.json`, `.env.example` и т.п.
- `tests/` – тесты (юнит-тесты, простые проверки).
- `artifacts/` – сохранённые модели, отчёты, результаты экспериментов.

Структура проекта в целом соответствует базовому шаблону. Дополнительно планируется использовать папку `artifacts/` для хранения промежуточных результатов, эмбеддингов и сохранённых артефактов моделей.

## 3. Требования и установка

### 3.1. Требования

- Python `>= 3.10` (уточните при необходимости).
- Установленные системные зависимости (если есть: например, `git`, `make` и т.п.).

### 3.2. Установка окружения

Примерный сценарий (можно адаптировать под ваш проект):

```bash
cd project
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

Для работы проекта дополнительно могут потребоваться библиотеки для обработки текста, поиска и API-сервиса (например scikit-learn, sentence-transformers, FastAPI). Полный список зависимостей будет указан в `requirements.txt`.

Настройка конфигурации:
Создайте файл .env в папке configs/ на основе шаблона:
```bash

cp configs/.env.example configs/.env

```
В .env можно добавить ключ API для LLM, если планируется использование OpenAI или другой языковой модели.

## 4. Как запустить проект

### 4.1. Запуск обучения модели

Обучение моделей выполняется внутри ноутбуков (`notebooks/`). Отдельного скрипта обучения нет — модели инициализируются при старте сервиса.

### 4.2. Запуск сервиса (API/веб-интерфейс)

```bash
cd project
source .venv/bin/activate
uvicorn src.service.api:app --reload
```

Сервис запускается на `http://localhost:8000` и предоставляет эндпоинты:

- `POST /ask` — поиск по запросу пользователя
- `GET /health` — проверка состояния сервиса

Интерактивная документация (Swagger UI): `http://localhost:8000/docs`

Или через Docker:

```bash
cd project
docker build -t rag-service .
docker run -p 8000:8000 rag-service
```
